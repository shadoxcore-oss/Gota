# Gota

**Gota** هي أداة مبنية باستخدام **Bash**، تهدف إلى تسهيل التعامل مع **Git** من خلال واجهة بسيطة تعمل من الطرفية.

يتوفر **Gota** حاليًا بإصدار **Gota version 1.0**، وهو النسخة الأولية من هذا المشروع، وسيتم العمل على تحسينه وإضافة ميزات أكثر في الإصدارات القادمة.

---

## 📦 التنصيب

### 1. استنساخ المستودع

قم باستنساخ مستودع Gota:

```bash
git clone https://github.com/shadoxcore-oss/Gota.git
```

ثم انتقل إلى مجلد المشروع:

```bash
cd gota
```

### 2. إعطاء صلاحية التنفيذ

قم بإعطاء سكريبت `gota` صلاحية التنفيذ:

```bash
chmod +x Gota
```

### 3. تثبيت Gota محليًا

أنشئ مجلد `~/.local/bin` إذا لم يكن موجودًا:

```bash
mkdir -p ~/.local/bin
```

ثم انسخ سكريبت Gota إليه:

```bash
cp gota ~/.local/bin/
```

### 4. إضافة `~/.local/bin` إلى PATH

تحقق أولًا مما إذا كان `~/.local/bin` موجودًا في `PATH`:

```bash
echo "$PATH"
```

إذا ظهر مسار مشابه لـ:

```text
/home/username/.local/bin
```

فيمكنك تجاوز هذه الخطوة.

إذا لم يكن موجودًا، أضفه إلى إعدادات Bash:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```

ثم أعد تحميل إعدادات Bash:

```bash
source ~/.bashrc
```

### 5. التحقق من نجاح التنصيب

تحقق من مكان تثبيت Gota:

```bash
which gota
```

يجب أن يظهر مسار مشابه لـ:

```text
/home/username/.local/bin/gota
```

بعد ذلك يمكنك تشغيل Gota من أي مكان في الطرفية:

```bash
gota
```


## 🗑️ إزالة Gota

لإزالة Gota من النظام، احذف الملف من `~/.local/bin`:

```bash
rm ~/.local/bin/gota
```
