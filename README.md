# Gota


 هي أداة مبنية باستخدام **Bash**، تهدف إلى تسهيل التعامل مع **Git** من خلال واجهة بسيطة تعمل من الطرفية.

يتوفر **Gota** حاليًا بإصدار **Gota-v1.1**، ويحتوي على مجموعة من الوظائف الأساسية لإدارة بعض عمليات Git من خلال واجهة تفاعلية بسيطة.

يتم تطوير المشروع بشكل مستمر، ومن المخطط إضافة المزيد من الميزات وتحسين تجربة الاستخدام في الإصدارات القادمة.

---

## 📦 التنصيب

### 1. استنساخ المستودع

قم باستنساخ مستودع Gota:

```bash
git clone https://github.com/shadoxcore-oss/Gota.git
```

ثم انتقل إلى مجلد المشروع:

```bash
cd Gota
```

### 2. تشغيل سكريبت التنصيب

قم بإعطاء سكريبت التنصيب صلاحية التنفيذ:

```bash
chmod +x install
```

ثم قم بتشغيله:

```bash
./install
```

سيقوم سكريبت التنصيب تلقائيًا بـ:

* إنشاء `~/.local/bin` إذا لم يكن موجودًا.
* البحث عن نسخة سابقة من `Gota` وحذفها.
* تثبيت نسخة Gota الجديدة في `~/.local/bin`.
* إعطاء `Gota` صلاحية التنفيذ.
* إضافة `~/.local/bin` إلى `PATH` إذا لم يكن موجودًا.
* تحديث `PATH` للجلسة الحالية.

بعد انتهاء التنصيب، يمكنك تشغيل Gota من أي مكان:

```bash
Gota
```

---

## 🗑️ إزالة Gota

لإزالة Gota من النظام، احذف النسخة المثبتة:

```bash
rm ~/.local/bin/Gota
```

إذا كنت قد أضفت `~/.local/bin` إلى `PATH` أثناء التنصيب، يمكنك إبقاؤه في `PATH` لاستخدامه مع برامج محلية أخرى، أو إزالة السطر الخاص به من:

```text
~/.bashrc
```

## ✨ الميزات الحالية

يتضمن Gota حاليًا مجموعة من الوظائف الأساسية، منها:

* إنشاء وتهيئة مستودع Git.
* إعداد Git Identity.
* عرض معلومات Git Identity.
* إضافة التغييرات وإنشاء Commit.
* حذف التغييرات غير المضافة إلى Staging.
* عرض الـ Branch الحالي.
* الانتقال بين Branches.
* إنشاء Branch انطلاقًا من Commit معين.
* حذف Branch.
* واجهة منظمة تشتغل من الترمينال
